# AUREN

> A responsive streetwear e-commerce frontend built with React and Vite.

## Overview

AUREN is a fashion e-commerce frontend focused on creating a polished shopping experience with a strong visual identity.

The project explores product presentation, responsive layouts, reusable React components, navigation, and interactive frontend experiences.

## Features

- Responsive e-commerce interface
- Product browsing and presentation
- Product detail views
- Category-based navigation
- Responsive navigation
- Reusable React components
- Interactive UI elements
- Mobile-friendly layouts
- Fashion-focused visual design

## Tech Stack

- React
- JavaScript (ES6+)
- Vite
- CSS

## Key Implementation Details

### Component-Based Architecture

The interface is built using reusable React components for common elements such as navigation, product cards, product sections, and other UI elements.

### Responsive Design

Layouts are designed to adapt across desktop, tablet, and mobile screen sizes.

### Product-Focused UI

The design prioritizes product presentation, visual hierarchy, spacing, typography, and clear navigation to create an e-commerce-oriented experience.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
git clone https://github.com/adityakumar2676/auren.git
cd auren
npm install
```

### Run Locally

```bash
npm run dev
```

The development server will provide a local URL in the terminal.
